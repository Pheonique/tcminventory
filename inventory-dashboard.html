ยังไม่ได้เชื่อมต่อฐานข้อมูล

ไฟล์นี้ใช้ Supabase (ฟรี) เป็นฐานข้อมูล ก่อนใช้งานให้ทำตามขั้นตอนนี้ก่อน:

  1. สมัครบัญชีฟรีที่ supabase.com แล้วสร้างโปรเจกต์ใหม่
  2. ไปที่ SQL Editor แล้วรันคำสั่งสร้างตารางที่ได้รับมาพร้อมไฟล์นี้
  3. ไปที่ Project Settings → API คัดลอกค่า Project URL และ anon public key
  4. เปิดไฟล์ inventory-dashboard.html ด้วยโปรแกรมแก้ไขข้อความ แล้วแก้ค่าในบรรทัดนี้ใกล้ด้านบนของ <script>:
const SUPABASE_URL = "https://YOUR-PROJECT.supabase.co";
const SUPABASE_ANON_KEY = "YOUR-ANON-KEY";

บันทึกไฟล์แล้วเปิดใหม่อีกครั้ง — ระบบจะเชื่อมต่อฐานข้อมูลให้อัตโนมัติ
